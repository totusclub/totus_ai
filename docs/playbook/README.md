## Как это работает

- `server/agentPlaybook.ts` подбирает к каждому сообщению клиента 1–2 подходящие темы по словам-триггерам. Предыдущее сообщение учитывается для коротких уточнений.
- Найденные темы добавляются в промпт только на этот шаг, раздел «Опыт турагента по теме этого сообщения».
- Обычный разговор («привет», «хочу в Турцию в ноябре») тему не получает.
- Сервер берёт данные из `server/agentPlaybookData.ts`. Источники остаются только здесь, в JSON.

## Как править

1. Изменить или добавить тему в `docs/playbook/*.json`. Поля:
   - `id`;
   - `title`;
   - `triggers` — основы слов в нижнем регистре, от 3 букв;
   - `ask`;
   - `advise`;
   - `facts` — `{text, source}`, источник обязателен;
   - `operator`;
   - `avoid`.
2. `npm run playbook:build` — сборка с проверкой.
3. `npm run check` — проверка `check-playbook` смотрит покрытие запросов владельца и то, что данные не спорят с правилами.

**Правила, которые данные не должны нарушать:**
- город вылета, даты и состав Маша уточняет сама и Москву не подставляет;
- номера не подбирает, только страница отеля и оператор;
- никаких телефонов и чужих сервисов.

Факты меняются: визы, сроки безвиза, сборы. Перепроверяйте их раз в сезон. Пример: с 15.09.2026 безвиз в Таиланд для россиян — 30 дней, с 01.11.2026 Черногория вводит визы для россиян.
